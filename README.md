# Dotfiles

Configuration for zsh, Vim, IdeaVim and Claude Code on macOS, kept in one repository and
symlinked into `$HOME`.

## Install

    git clone https://github.com/ricardslazda/.dotfiles.git ~/.dotfiles
    cd ~/.dotfiles
    ./symlink.sh

`symlink.sh` links `.zshrc`, `.vimrc`, `.ideavimrc`, `.p10k.zsh` and `.claude-statusline.sh` into
`$HOME`, skipping any the repository does not have. A real file already sitting there is moved to
`<name>.backup` first; an existing symlink is replaced. Editing a file in this repository changes
the live configuration, because the files in `$HOME` are symlinks pointing here.

## What each file does

| File              | Contents                                                                                                                                                             |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.zshrc`          | Zinit plugin manager, Powerlevel10k prompt, syntax highlighting, extra completions, fzf-tab, zsh-vi-mode, history behaviour, completion styles, aliases and functions |
| `.vimrc`          | Space as leader, line numbers, search and clipboard behaviour, vim-plug with NERDTree and devicons, window navigation and centred half-page scrolling                |
| `.ideavimrc`      | Sources `.vimrc`, then adds IdeaVim plugins and IDE action maps for navigation, splits, debugging, bookmarks, git blame and path copying                             |
| `.p10k.zsh`       | Powerlevel10k prompt appearance, generated by `p10k configure` and sourced from `.zshrc`                                                                             |
| `.claude-statusline.sh`   | Claude Code status line: directory, git branch, model, effort, context used, and the 5-hour and 7-day plan usage with reset times                             |
| `symlink.sh`      | Creates the symlinks in `$HOME`, backing up any real file it would replace                                                                                           |

## Shortcuts

`b` btop, `e` extract, `t` tldr, `g` lazygit, `d` lazydocker, `p` pet exec, `r` repomix,
`v` vim in the current directory or on the given files.

In Vim the leader is space: `<leader>e` toggles NERDTree, `<leader>w` writes, `<leader>q` quits,
`<leader>y` yanks to the system clipboard, `<leader>/` clears the search highlight. `Shift+j` and
`Shift+k` scroll by half a page. IdeaVim adds `<leader>sv` and `<leader>sh` for splits, `<leader>d`
prefixed maps for the debugger, and `F6` to `F10` for stepping.

## What it expects

Homebrew, and on `PATH`: `fzf`, `zoxide`, `btop`, `tldr`, `lazygit`, `lazydocker`, `pet` and
`repomix`. The status line needs `jq`, which macOS ships at `/usr/bin/jq`. Zinit installs itself on first shell start. Vim needs
[vim-plug](https://github.com/junegunn/vim-plug) and then `:PlugInstall`; the devicons plugin needs
a Nerd Font. IdeaVim needs the EasyMotion and IdeaVim-Sandwich plugins for the `easymotion` and
`surround` settings.

## Editing `.zshrc`

Zoxide has to be initialised by the last line of the file, so add new `PATH` entries and other
setup above the `Fzf and Zoxide` section. Putting anything after it makes zoxide print a
configuration warning on every shell start.

## Claude Code

`~/.claude` is disposable. This command wipes it, writes the settings and reinstalls the plugins:

    rm -rf ~/.claude && mkdir -p ~/.claude && \
    printf '{\n  "editorMode": "vim",\n  "theme": "dark",\n  "statusLine": {\n    "type": "command",\n    "command": "~/.claude-statusline.sh",\n    "padding": 0,\n    "refreshInterval": 60\n  }\n}\n' > ~/.claude/settings.json && \
    claude plugin marketplace add anthropics/claude-plugins-official && \
    claude plugin install frontend-design@claude-plugins-official -y && \
    claude plugin install skill-creator@claude-plugins-official -y && \
    claude plugin install mattpocock-skills@claude-plugins-official -y

The status line script sits outside `~/.claude`, so the reset never touches it. It reads one JSON
object on stdin and prints one line:

    .dotfiles · main · Opus 5 (high) · ctx 34% · 5h 12% (09:44) · 7d 74% (Tue 15:17)

The branch comes from `git symbolic-ref`, and falls back to the short commit on a detached HEAD.
It is absent outside a repository. The bracketed word is the reasoning effort level, shown only on
a model that supports it. `ctx` is the context used in the session. `5h` and `7d` are the plan
limits used, with the local clock time each window resets. The time shows the weekday too when the
reset falls on another day. Green under 70% used, yellow from 70%, red from 90%. Claude Code sends
the `rate_limits` fields only on a Claude.ai plan, so an API key, Bedrock or Vertex login omits the
last two parts.
